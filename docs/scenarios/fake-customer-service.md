# 冒充客服退款诈骗

## 典型案例

> "我妈接到电话说快递丢了要退款，差点把验证码报出去"

## 诈骗话术

- "您好，我是XX快递/XX平台客服"
- "您的快递丢失了，要给您办理退款"
- "您的商品有质量问题，需要召回退款"
- "您开通了XX会员，每月要扣费，需要取消"
- "退款需要下载APP/开启屏幕共享"
- "需要您提供验证码/银行卡号"

## 危险信号 🚩

| 信号 | 说明 |
|------|------|
| 主动来电 | 真正的客服不会主动打电话要求退款 |
| 要求下载APP | 任何要求下载陌生软件的都是骗子 |
| 屏幕共享 | 开启屏幕共享=对方能看到你的一切操作 |
| 索要验证码 | 验证码=密码，绝对不能给任何人 |
| 要求转账 | 退款不需要你先转账 |

## 识别要点

**记住一句话：**
> 任何主动来电要求退款/取消扣费的，99%是骗子。

**正确的退款流程：**
1. 你主动申请退款
2. 通过官方APP/网站操作
3. 退款原路返回，不需要提供验证码

## 应对措施

### 如果父母正在接电话

1. **立即打断** - 大声说"先挂电话，这是骗子"
2. **确认状态** - 问"有没有下载APP？有没有给验证码？"
3. **检查手机** - 看是否安装了陌生软件
4. **修改密码** - 如果已泄露信息，立即修改支付密码

### 如果父母已经操作

1. **立即冻结银行卡** - 拨打银行客服电话
2. **检查账户** - 查看是否有异常转账
3. **保存证据** - 截图通话记录、短信
4. **报警** - 拨打96110

## 和父母怎么说

### ❌ 不要这样说
- "你怎么这么笨，这明显是骗子！"
- "我说了多少次不要接陌生电话！"

### ✅ 建议这样说
- "先挂电话，任何退款都要通过官方APP操作"
- "真正的客服不会要验证码，给验证码就是给密码"
- "下次有退款，先问我，我帮你操作"

## 预防建议

1. **告诉父母：** 所有"客服"来电都是骗子，有问题通过官方APP联系
2. **设置权限：** 关闭手机"允许安装未知应用"
3. **建立规则：** 任何退款、扣费问题，先问子女
