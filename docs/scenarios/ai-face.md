# AI换脸/拟声诈骗

## 套路解析

利用AI技术伪造子女或熟人的视频/声音，以"急需用钱"为由诱导老人转账。

## 典型话术

- "妈，我出事了，急需用钱"
- "视频里是我，你还不信吗"
- "不要告诉我爸，他会担心"
- "快点转账，时间紧迫"

## 危险信号

1. 视频通话但画面卡顿或声音延迟
2. 要求保密不告诉其他家人
3. 催促立即转账
4. 提供的收款账户不是本人

## 应对方法

1. **多渠道核实** - 挂断后打子女本人电话确认
2. **询问私密问题** - 只有真人才知道的事
3. **绝不紧急转账** - 任何紧急情况都先核实
4. **约定暗号** - 和家人约定转账暗号

## 真实案例

> 我奶奶接到"我"的视频电话，说急需5万块交医疗费。视频里确实是我的样子，但我奶奶觉得声音不太对，给我打了电话，发现是AI换脸。
> 
> —— 来自用户投稿

## 技术说明

AI换脸技术（Deepfake）可以伪造逼真的视频，但通常有以下破绽：
- 表情不自然，眨眼频率异常
- 边缘模糊或闪烁
- 声音与口型不同步
- 光线变化不自然
