# 旅游/社区团购诈骗

## 套路解析

以"低价旅游"、"社区团购"为名，诱导老人参加强制购物团或预付大额费用后跑路。

## 典型话术

- "99元游云南，包吃包住"
- "社区团购，比超市便宜一半"
- "预存1000送500"
- "限时团购，错过再等一年"

## 危险信号

1. 价格明显低于市场价
2. 要求预存大额费用
3. 行程中有大量购物点
4. 公司资质不明

## 应对方法

1. **选择正规旅行社** - 查看营业执照和旅游许可证
2. **签订正规合同** - 明确行程和费用
3. **不预存大额费用** - 避免资金风险
4. **子女陪同或把关** - 特别是出境游
