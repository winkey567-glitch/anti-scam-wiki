# 情感/婚恋诈骗

## 套路解析

骗子通过社交平台、相亲网站等渠道，伪装成"贴心伴侣"，建立感情后以各种理由借钱或诱导投资。

## 典型话术

- "我一个人很孤独，想找个人陪伴"
- "我生病了，需要钱看病"
- "我有个赚钱的项目，一起投资吧"
- "等我处理好事情就去找你"

## 危险信号

1. 进展过快，很快谈婚论嫁
2. 各种理由借钱
3. 拒绝视频见面
4. 诱导投资或转账

## 应对方法

1. **核实身份** - 要求视频通话，核实真实信息
2. **绝不借钱** - 没见过面的人不要借钱
3. **告诉子女** - 让子女帮忙把关
4. **警惕"杀猪盘"** - 感情+投资双重套路
