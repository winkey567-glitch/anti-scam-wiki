# 刷单返利诈骗

## 套路解析

以"兼职刷单"、"点赞赚钱"为名，先让老人垫付小额，再要求垫付大额，最终钱被骗走。

## 典型话术

- "动动手指就能赚钱"
- "垫付100返120，垫付1000返1300"
- "任务未完成，需要继续垫付"
- "系统故障，需要再刷一单"

## 危险信号

1. 先垫付后返利
2. 要求连续垫付
3. 无法提现各种理由
4. 拉人头有奖励

## 应对方法

1. **刷单就是违法** - 本身就是违法行为
2. **绝不垫付** - 任何要求先付钱的都是骗
3. **不贪小利** - 小便宜后面是大陷阱
4. **及时止损** - 发现被骗立即报警

## 真实案例

> 我妈被拉进一个"点赞群"，开始确实返了几块钱，后来让垫付5000块做"高级任务"。她垫付后对方说系统故障，需要再垫付1万。幸好我及时发现并报警。

## 法律提醒

刷单本身就是违法行为，参与刷单可能面临法律风险。任何要求垫付的"兼职"都是诈骗。
