# 养老投资诈骗

## 套路解析

以"养老项目"、"高息理财"、"国家扶持"为名，承诺高额回报，诱导老人投资，最终血本无归。

## 典型话术

- "国家养老项目，保本保息"
- "年化收益15%，比银行高多了"
- "投资养老床位，每月返租金"
- "虚拟货币养老，稳赚不赔"

## 危险信号

1. 承诺"高收益、零风险"
2. 要求拉人头有奖励
3. 投资方式不透明
4. 催促尽快决定

## 应对方法

1. **高收益=高风险** - 超过6%就要打问号
2. **正规渠道理财** - 银行、证券公司
3. **子女参与决策** - 大额投资必须商量
4. **查询备案信息** - 上银保监会网站核实

## 真实案例

## 法律规定

根据《防范和处置非法集资条例》，任何单位和个人不得从事非法集资活动。参与非法集资，损失自行承担。
