# 保健品/养生诈骗

## 套路解析

骗子利用老年人对健康的焦虑，通过免费体检、健康讲座、专家义诊等方式，推销高价虚假保健品或理疗仪器。

## 典型话术

- "免费体检，专家一对一咨询"
- "这个药能治百病，纯天然无副作用"
- "限时优惠，买三送一"
- "很多老干部都在吃这个"
- "最后一天，错过就没有了"

## 危险信号

1. "包治百病"、"根治慢性病"
2. 宣称"纯天然"、"无副作用"
3. 免费体检后必有"大问题"
4. 限时优惠、饥饿营销
5. 冒充专家、伪造资质

## 应对方法

1. **正规医院就医** - 有病去正规医院，不要轻信"专家"
2. **查询批准文号** - 上国家药监局网站核实
3. **拒绝免费诱惑** - 免费的东西往往最贵
4. **子女把关** - 大额消费必须经子女同意

## 真实案例

> 我爸被拉去听健康讲座，买了3万块的理疗床垫，说是能治疗高血压、糖尿病。我查了一下，就是个普通电热毯，成本几百块。
> 
> —— 来自用户投稿

## 防骗口诀

**病急不乱投医，免费必有猫腻。**
**正规医院最靠谱，保健品不是药。**
