## 如何阅读

1. **了解套路** - 先看诈骗话术，知道骗子怎么说
2. **掌握识别** - 记住危险信号，第一时间识破
3. **学会应对** - 知道该说什么、做什么
4. **教给父母** - 用他们能理解的方式讲解
