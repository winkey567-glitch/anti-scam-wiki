# 中奖/免费送礼诈骗

## 套路解析

以"中奖"、"免费领礼品"为诱饵，诱导老人支付"手续费"、"税费"或填写个人信息，最终礼品没有，钱被骗走。

## 典型话术

- "恭喜您中了一等奖！"
- "免费领鸡蛋/米面油"
- "扫码领红包"
- "只需支付运费/税费"

## 危险信号

1. 先交钱后领奖
2. 要求提供银行卡信息
3. 要求扫码下载APP
4. 领奖地点在偏僻处

## 应对方法

1. **天上不会掉馅饼** - 真有好事不会找上你
2. **绝不先交钱** - 任何要求先交钱的"奖励"都是骗
3. **不扫码** - 陌生二维码不要扫
4. **告诉子女** - 让子女帮忙判断
