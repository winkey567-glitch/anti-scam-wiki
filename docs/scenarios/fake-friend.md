# 假冒熟人/子女求助诈骗

## 套路解析

冒充子女、亲友、老同事，以"出事了"、"急需用钱"为由借钱。

## 典型话术

- "爸，我手机坏了，换了个号"
- "我出车祸了，需要医药费"
- "我被抓了，需要保释金"
- "我在外地，钱包丢了"

## 危险信号

1. 电话号码陌生
2. 要求保密不告诉其他人
3. 催促立即转账
4. 拒绝视频通话

## 应对方法

1. **回拨确认** - 挂断后打原号码确认
2. **问私密问题** - 只有真人才知道的事
3. **联系其他亲友** - 多方核实
4. **绝不紧急转账** - 任何紧急情况都先冷静
