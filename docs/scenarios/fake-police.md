# 冒充公检法诈骗

## 套路解析

骗子冒充公安、检察院、法院工作人员，声称老人涉嫌洗钱、贩毒等重大案件，要求配合调查并转账到"安全账户"。

## 典型话术

- "我是XX市公安局的，你涉嫌洗钱"
- "你的身份证被冒用，需要配合调查"
- "不要告诉任何人，包括家人"
- "把钱转到安全账户，调查完会退还"

## 危险信号

1. 要求保密，不准告诉家人
2. 要求转账到"安全账户"
3. 发送伪造的通缉令、逮捕令
4. 要求视频通话"做笔录"

## 应对方法

1. **立即挂断** - 公检法不会电话办案
2. **拨打110核实** - 通过官方渠道确认
3. **绝不转账** - 没有"安全账户"这回事
4. **告诉家人** - 打破骗子的信息隔离

## 真实案例

> 我妈接到"公安局"电话说她涉嫌洗钱，让她把存款转到"安全账户"配合调查。骗子还发了一张通缉令照片，把她吓坏了。幸好她给我打了电话，我让她立即挂断并报警。
> 
> —— 来自用户投稿

## 紧急提醒

**公检法机关绝不会：**
- 通过电话、网络办案
- 要求转账到"安全账户"
- 要求提供银行卡密码、验证码
- 要求保密不告诉家人

如遇此类电话，**立即挂断并拨打110报警**。
