# 人群分类总览

不同性格、生活习惯的老人，易受骗的类型也不同。了解父母属于哪种类型，才能针对性防范。

## 七大易骗人群

### [孤独空巢型](/profiles/lonely)
**特征：** 独居、缺陪伴、易信陌生人  
**易感骗局：** 情感诈骗、上门推销、假干儿子干女儿

### [健康焦虑型](/profiles/health-anxiety)
**特征：** 怕生病、信特效、爱养生  
**易感骗局：** 保健品、理疗仪器、虚假名医

### [贪小便宜型](/profiles/greedy)
**特征：** 节俭、爱薅羊毛、信免费  
**易感骗局：** 免费领礼品、返利诈骗、中奖诈骗

### [盲目投资型](/profiles/investor)
**特征：** 想钱生钱、信高回报  
**易感骗局：** 养老理财、虚拟货币、项目入股

### [认知衰退型](/profiles/cognitive)
**特征：** 记忆力差、分辨弱  
**易感骗局：** 冒充公检法、转账诈骗、简单套路

### [热衷社交型](/profiles/social)
**特征：** 爱社群、广场舞、旅游  
**易感骗局：** 社群团购、旅游购物、熟人推荐

### [技术懵懂型](/profiles/tech-illiterate)
**特征：** 不会用手机、易点链接  
**易感骗局：** 扫码诈骗、钓鱼链接、APP诱导
