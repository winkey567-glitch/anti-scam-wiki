# 热衷社交/社群型老人

## 人群特征

- 喜欢参加老年社群活动
- 热衷广场舞、老年旅游
- 喜欢同学聚会、社区活动
- 社交圈子广，朋友多
- 容易相信"熟人"推荐

## 为什么容易被骗

社交型老人信任"群里的朋友"、"一起跳舞的姐妹"，认为"熟人不会骗我"。骗子利用这种信任，通过社群渗透、熟人推荐等方式实施传销或诈骗。

## 常见骗局

| 骗局类型 | 套路 | 渠道 |
|---------|------|------|
| 社群团购 | 低价商品 | 微信群 |
| 旅游购物 | 强制购物团 | 旅行社 |
| 群内集资 | 一起投资项目 | 熟人推荐 |
| 熟人传销 | 拉人头奖励 | 朋友推荐 |
| 保健品推销 | 姐妹都在吃 | 广场舞群体 |

## 子女应对策略

### 1. 社群筛选把关

- **了解参加的社群**：询问老人参加了哪些群
- **甄别正规性**：是否为官方组织
- **劝阻陌生商业群**：退出不明来源的群
- **定期检查群列表**：关注新加入的群

### 2. 群内信息甄别

教老人规则：

> **群里的推销、投资、借钱信息，一律不信。**

> **不参与群内非正规消费、集资活动。**

> **即使是熟人推荐，也要先问子女。**

### 3. 结伴出行管控

- **了解行程**：老人参加活动必须告知子女
- **拒绝低价团**：不参加明显低于市场价的旅游团
- **查看资质**：旅行社是否有正规许可证
- **签订合同**：正规旅游合同，明确行程

### 4. 打破熟人滤镜

- **讲解案例**：社群熟人传销、诈骗的真实案例
- **强调规则**：即使是朋友推荐，也要核实
- **建立边界**：涉及钱的事情，必须子女把关
- **保持警惕**：熟人也可能被骗，成为帮凶

## 沟通技巧

**不要说：**
- "你那些朋友都是骗子！"
- "以后不准去跳舞了！"
- "你怎么这么容易相信别人？"

**建议说：**
- "我知道你喜欢和朋友在一起，但涉及钱的事情要小心。"
- "即使是好朋友推荐，也先让我帮你看看。"
- "很多骗子就是专门混进老年群体的。"

## 识别问题社群

### 危险信号

- 经常发商品广告、投资信息
- 鼓励拉人头有奖励
- 组织不明来源的团购
- 推销高价保健品
- 组织低价旅游

### 建议退出的群

- 商业推销群
- 投资理财群
- 不明来源的团购群
- 要求拉人头的群

## 替代方案

| 老人需求 | 危险方式 | 安全替代 |
|---------|---------|---------|
| 社交 | 问题社群 | 社区老年活动中心 |
| 旅游 | 低价购物团 | 正规旅行社 |
| 购物 | 群内团购 | 正规电商平台 |
| 学习 | 收费养生课 | 社区免费讲座 |

## 紧急处理

如果发现老人通过社群被骗：

1. **收集证据**：聊天记录、转账记录
2. **报警处理**：拨打110
3. **提醒其他老人**：在群里提醒其他人
4. **退出问题群**：立即退出诈骗群
5. **举报群聊**：向平台举报

## 建立安全社交圈

帮助老人建立健康的社交圈：

- 社区老年活动中心
- 正规老年大学
- 公园健身群体
- 子女朋友的长辈
- 正规兴趣社团

关键是：**有组织者、有固定场所、不涉及金钱往来。**
