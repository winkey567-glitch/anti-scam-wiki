# 技术懵懂型老人

## 人群特征

- 不熟悉智能手机和互联网
- 对新技术感到困惑
- 容易误操作
- 无法识别网络诈骗
- 对"官方"、"系统"等词缺乏判断力

## 为什么容易被骗

技术懵懂让老人无法分辨真假网站、APP、短信。骗子利用"系统升级"、"账户异常"等技术话术，诱导老人操作手机，最终盗取资金或信息。

## 常见骗局

| 骗局类型 | 套路 | 技术手段 |
|---------|------|---------|
| 冒充客服 | 账户异常需处理 | 伪造官方页面 |
| 系统升级 | 需重新认证 | 钓鱼链接 |
| 病毒警告 | 手机中毒了 | 虚假弹窗 |
| 远程协助 | 帮你操作手机 | 屏幕共享盗刷 |
| APP诱导 | 下载指定软件 | 木马程序 |

## 子女应对策略

### 1. 基础安全设置

- **关闭自动下载**：防止误装软件
- **关闭未知来源安装**：只从应用商店下载
- **设置应用锁**：支付软件加密码
- **开启查找手机**：丢失可定位

### 2. 操作权限管控

- **不告知支付密码**：老人不知道密码
- **关闭指纹/人脸支付**：避免误操作
- **设置支付限额**：单笔和日限额
- **关闭免密支付**：所有支付需密码

### 3. 识别教育

教老人识别：

**真客服不会：**
- 主动打电话说账户异常
- 要求转账到"安全账户"
- 要求下载陌生软件
- 要求屏幕共享

**陌生链接不要点：**
- 短信里的链接
- 微信里的链接
- 邮件里的链接
- 弹窗广告

### 4. 建立求助习惯

- **任何操作前先问**：不确定的操作先问子女
- **截图发子女**：看到可疑信息先截图
- **不自行解决**：遇到问题不自己尝试解决
- **定期清理手机**：子女定期帮老人检查手机

## 沟通技巧

**不要说：**
- "这个很简单啊，你怎么不会？"
- "我教了你多少次了！"
- "你就别用手机了！"

**建议说：**
- "没关系，我帮你弄。"
- "这个功能有点复杂，下次我慢慢教你。"
- "有任何提示都先问我，不要自己点。"

## 手机安全清单

### 必须关闭的功能

- [ ] 未知来源应用安装
- [ ] 自动下载彩信
- [ ] 浏览器自动填充密码
- [ ] APP的敏感权限（通讯录、短信等）

### 必须开启的功能

- [ ] 应用商店自动更新
- [ ] 系统安全更新
- [ ] 查找我的设备
- [ ] 骚扰拦截

### 定期检查

- [ ] 查看已安装APP列表
- [ ] 检查是否有陌生软件
- [ ] 查看短信里的验证码记录
- [ ] 检查是否有异常扣费

## 常见技术话术破解

| 骗子话术 | 真相 | 应对 |
|---------|------|------|
| "系统检测到异常" | 假的，系统不会主动打电话 | 挂断，自己登录官方APP查看 |
| "需要重新认证" | 钓鱼网站想骗密码 | 绝不点击链接，官方APP内操作 |
| "下载这个软件我帮你操作" | 远程控制盗刷 | 绝不下载，绝不屏幕共享 |
| "不操作账户会被冻结" | 制造紧迫感 | 冷静，联系官方客服核实 |

## 紧急处理

如果老人已经：

### 点击了可疑链接

1. 立即退出页面
2. 不要输入任何信息
3. 修改相关密码
4. 检查账户是否有异常

### 下载了陌生软件

1. 立即卸载
2. 修改支付密码
3. 检查账户余额
4. 必要时恢复出厂设置

### 进行了屏幕共享

1. 立即停止共享
2. 检查是否有转账记录
3. 冻结银行卡
4. 报警处理

## 长期防护

- 给老人买操作简单老人机作为备用
- 定期帮老人清理手机、检查APP
- 教会老人使用语音助手，减少操作难度
- 建立"有问题先问子女"的习惯
