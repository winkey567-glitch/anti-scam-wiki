# 孤独空巢型老人

## 人群特征

- 子女常年不在身边
- 独居或和老伴相依为命
- 缺乏情感陪伴和交流
- 渴望与人沟通
- 社交圈子狭窄

## 为什么容易被骗

孤独感让老人极度渴望被关心、被需要。骗子正是利用这一点，通过频繁电话、上门拜访、认干亲等方式，填补老人的情感空缺，建立信任后实施诈骗。

## 常见骗局

| 骗局类型 | 套路 | 目标 |
|---------|------|------|
| 情感诈骗 | 认干儿子/干女儿 | 骗取钱财 |
| 上门推销 | 陪聊天、做家务 | 推销高价产品 |
| 免费礼品 | 送鸡蛋、米面 | 获取个人信息 |
| 虚假陪伴 | 组织活动、旅游 | 诱导消费 |

## 子女应对策略

### 1. 高频情感填补

- **每天固定联系**：至少10分钟视频/语音通话
- **主动分享日常**：让老人感觉被需要、被重视
- **丰富社交圈**：帮老人联系老同事、老朋友
- **鼓励社区活动**：参加正规的老年活动中心

### 2. 上门人员管控

- **明确告知老人**：任何上门推销、陌生访客，一律先联系子女
- **安装可视门铃**：子女可远程查看访客
- **设置门禁规则**：未经允许绝不开门、不收钱

### 3. 话术演练

教老人拒绝话术：

> "我做不了主，所有钱都在孩子那，等我子女回来再说。"

> "你留下联系方式，我让孩子联系你。"

### 4. 日常预警

- 多分享同类老人被骗案例
- 用真实故事强化警惕心
- 让老人知道骗子的常见套路

## 沟通技巧

**不要说：**
- "你怎么这么容易被骗？"
- "我早就告诉过你..."
- "你怎么又..."

**建议说：**
- "最近这种套路很多，我先帮你看看。"
- "谢谢你告诉我，我们一起想办法。"
- "你做得对，遇到不确定的事情就该问我。"

## 紧急处理

如果发现老人已经被骗：

1. **不要指责** - 先安抚情绪
2. **立即报警** - 拨打110或96110
3. **保留证据** - 聊天记录、转账凭证
4. **联系银行** - 尝试止付

## 长期防护

- 考虑安装家庭监控（征得老人同意）
- 定期带老人体检，关注心理健康
- 考虑请保姆或送正规养老院
- 教会老人使用智能手机，方便随时联系
