# 贪小便宜型老人

## 人群特征

- 生活节俭，精打细算
- 热衷免费福利、薅羊毛
- 喜欢打折、满减、抽奖
- 容易被"免费领"、"0元购"吸引
- 对价格敏感，追求性价比

## 为什么容易被骗

节俭本是美德，但过度追求"免费"和"便宜"容易让老人忽视风险。骗子利用"免费领礼品"、"扫码领红包"等诱饵，诱导老人泄露个人信息或支付小额费用，最终被骗走更多钱。

## 常见骗局

| 骗局类型 | 诱饵 | 陷阱 |
|---------|------|------|
| 免费领礼品 | 鸡蛋、米面、油 | 获取个人信息、诱导消费 |
| 购物返利 | 买100返120 | 垫付后无法提现 |
| 低价团购 | 超低价商品 | 收款后跑路 |
| 中奖诈骗 | 中手机、中现金 | 先交税费/手续费 |
| 扫码领福利 | 红包、优惠券 | 盗取信息或植入病毒 |

## 子女应对策略

### 1. 利弊直白科普

用简单直白的话讲清逻辑：

> "免费的东西最贵，最终都会骗走更多钱。"

> "天上不会掉馅饼，真有好事不会找上你。"

列举身边真实案例：
- 邻居王阿姨领免费鸡蛋被骗5000元
- 李叔叔扫码领红包被盗刷银行卡

### 2. 日常需求满足

- **主动采购**：帮老人买齐生活用品
- **正规优惠**：教老人使用正规平台优惠券
- **杜绝接触**：不让老人为贪小便宜接触陌生人
- **满足心理**：理解老人节俭心理，给予肯定

### 3. 操作权限管控

- **禁止随意扫码**：陌生二维码一律不扫
- **不点陌生链接**：短信、微信里的链接不点
- **不填个人信息**：不随便登记姓名电话
- **设置支付限额**：限制单笔和日累计金额

### 4. 及时制止行为

发现老人参加可疑活动：

1. **立即劝阻**：温和但坚定地制止
2. **讲解套路**：说明骗子的完整流程
3. **带离现场**：如果是线下活动，直接带走
4. **报警处理**：如果涉及诈骗团伙

## 沟通技巧

**不要说：**
- "就为了几个鸡蛋，值得吗？"
- "你怎么这么贪小便宜？"
- "我说了多少次了！"

**建议说：**
- "这个免费活动我查了一下，后面会让你买高价东西。"
- "你想要什么我去超市买，别去领这些来路不明的。"
- "我知道你想省钱，但这种'免费'后面有大坑。"

## 防骗口诀

**免费鸡蛋是诱饵，个人信息被拿走。**
**扫码领红包是假，银行卡被盗刷。**
**低价团购要小心，收款跑路没处找。**
**天上不会掉馅饼，真有好事轮不到你。**

## 替代方案

| 老人需求 | 危险方式 | 安全替代 |
|---------|---------|---------|
| 省钱 | 参加免费活动 | 教用正规优惠券 |
| 社交 | 去领礼品现场 | 参加社区活动 |
| 成就感 | 薅羊毛 | 培养兴趣爱好 |
| 被关心 | 和推销员聊天 | 子女多陪伴 |
