# 认知衰退型老人

## 人群特征

- 年纪较大（通常75岁以上）
- 记忆力明显下降
- 反应迟钝，理解力减弱
- 分辨能力弱化
- 容易轻信他人

## 为什么容易被骗

认知衰退让老人难以识别复杂骗局，容易忘记之前的提醒，对陌生人的防备心降低。骗子利用老人的善良和信任，用简单直接的套路实施诈骗。

## 常见骗局

| 骗局类型 | 套路 | 特点 |
|---------|------|------|
| 冒充公检法 | 说你犯法了 | 利用恐惧心理 |
| 冒充子女 | 出事了急需钱 | 简单直接 |
| 转账诈骗 | 各种理由让转账 | 容易上当 |
| 简单套路 | 不复杂的话术 | 老人能理解 |

## 子女应对策略

### 1. 全权财务管控

- **保管银行卡**：老人不持有大额资金
- **保管身份证**：防止被冒用
- **管理支付密码**：关闭手机支付或设置限额
- **每月给生活费**：固定金额，避免大额资金

### 2. 专属求助通道

- **设置一键拨号**：手机设置子女快捷拨号
- **明确规则**：遇到任何陌生要求，第一时间联系子女
- **反复强调**：经常提醒老人这个规则
- **耐心解释**：老人可能忘记，需要反复说

### 3. 外界信息隔离

- **过滤陌生来电**：设置白名单，只接熟人电话
- **过滤短信**：屏蔽垃圾短信
- **卸载陌生软件**：只保留必要的APP
- **关闭网络支付**：避免线上转账

### 4. 贴身陪伴/监护

- **家人陪护**：条件允许请家人陪伴
- **请保姆**：找可靠的住家保姆
- **社区养老**：联系社区养老帮扶
- **养老院**：考虑送正规养老院

## 沟通技巧

**不要说：**
- "你怎么又忘了？"
- "我不是说过吗？"
- "你怎么这么糊涂？"

**建议说：**
- "没关系，我再说一遍。"
- "你做得对，有疑问就问我。"
- "这个我来处理，你不用管。"

## 手机设置建议

### 基础设置

1. **关闭陌生来电**：只接听通讯录联系人
2. **关闭短信链接**：防止误点
3. **卸载支付软件**：或设置每日限额100元
4. **设置紧急联系人**：长按电源键可拨打

### 推荐APP

- **大字体拨号**：界面简单
- **定位共享**：随时知道老人位置
- **远程协助**：子女可远程帮助操作

## 识别认知衰退信号

如果出现以下情况，需要特别关注：

- 经常忘记刚发生的事
- 反复问同一个问题
- 无法完成熟悉的任务
- 判断力明显下降
- 性格突然改变
- 走失或迷路

建议及时就医，评估认知状况。

## 紧急处理

如果发现老人已经被骗：

1. **不要责怪** - 老人已经很难过了
2. **立即报警** - 拨打110
3. **联系银行** - 尝试止付
4. **加强看护** - 避免再次被骗
5. **评估状况** - 考虑是否需要更严格的监护

## 长期防护

- 定期带老人体检，包括认知评估
- 考虑法律手段：申请监护权
- 建立家庭轮班制度，确保有人陪伴
- 与社区、邻居建立联系，互相照应
