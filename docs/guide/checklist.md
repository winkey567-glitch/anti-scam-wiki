# 家庭防骗基础配置清单

## 手机安全设置

### 基础设置

- [ ] **关闭未知来源应用安装**
  - 安卓：设置 → 安全 → 未知来源（关闭）
  - iOS：默认关闭，无需设置

- [ ] **关闭自动下载彩信**
  - 防止收到恶意彩信自动下载

- [ ] **开启骚扰拦截**
  - 安装国家反诈中心APP
  - 开启手机自带骚扰拦截

- [ ] **设置锁屏密码**
  - 不要使用简单密码（如123456）
  - 定期更换密码

### 支付安全

- [ ] **设置支付限额**
  - 单笔限额：建议500元以内
  - 日累计限额：建议1000元以内

- [ ] **关闭免密支付**
  - 所有支付都需要密码确认

- [ ] **关闭自动续费**
  - 检查并关闭不需要的自动续费

- [ ] **不绑定大额银行卡**
  - 只绑定日常零花钱账户

## 银行卡安全

- [ ] **设置转账限额**
  - 网银转账限额设为较低金额
  - 大额转账需到柜台办理

- [ ] **开通短信提醒**
  - 任何交易都有短信通知
  - 子女也可接收提醒（如银行支持）

- [ ] **保管好银行卡**
  - 不随意交给他人
  - 不拍照发给陌生人

- [ ] **定期查账**
  - 每月查看银行流水
  - 发现异常立即处理

## 家庭规则

### 必须遵守的规则

- [ ] **验证码绝不告知任何人**
  - 银行、客服、公检法都不会要验证码
  - 任何人要验证码都是骗子

- [ ] **转账前必须电话确认**
  - 即使是"子女"、"熟人"要求转账
  - 挂断后打原号码确认

- [ ] **大额消费必须子女同意**
  - 设定金额阈值（如1000元）
  - 超过必须告知子女

- [ ] **不安装陌生软件**
  - 只从官方应用商店下载
  - 不扫描陌生二维码下载

### 建议遵守的规则

- [ ] **陌生电话不接**
  - 不认识的号码不接
  - 接听后涉及钱立即挂断

- [ ] **免费活动不参加**
  - 免费领礼品、免费体检等
  - 免费的东西往往最贵

- [ ] **不点击陌生链接**
  - 短信、微信里的链接不点
  - 官方APP内操作

- [ ] **不屏幕共享**
  - 任何人要求屏幕共享都是骗子
  - 包括"客服"、"技术人员"

## 定期检查清单

### 每周检查

- [ ] 询问父母是否有可疑电话/信息
- [ ] 查看手机是否有陌生APP
- [ ] 检查是否有异常扣费短信

### 每月检查

- [ ] 查看银行流水
- [ ] 检查手机安全设置
- [ ] 更新骚扰拦截规则
- [ ] 和父母回顾防骗规则

### 每季度检查

- [ ] 全面检查手机APP列表
- [ ] 检查社交软件好友列表
- [ ] 评估父母认知状况
- [ ] 调整防护措施（如需要）

## 应急准备

### 紧急联系人

确保父母手机里有：
- [ ] 子女电话（设置为一键拨号）
- [ ] 报警电话110
- [ ] 反诈专线96110
- [ ] 银行客服电话
- [ ] 社区/物业电话

### 应急预案

如果发现父母正在被诈骗：

1. **立即联系父母**：确认是否正在转账
2. **要求停止操作**：不要继续输入验证码
3. **联系银行止付**：拨打银行客服冻结账户
4. **保留证据**：聊天记录、转账记录、电话号码
5. **报警**：拨打110或96110

## 完成度检查

完成以上清单后，评估家庭防骗等级：

- **90%以上**：优秀，防护到位
- **70-89%**：良好，继续完善
