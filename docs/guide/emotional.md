# 当父母被骗后：子女情绪支持指南

## 你可能正在经历的情绪

发现父母被骗后，很多子女会经历以下情绪：

- **愤怒**："骗子太可恶了！"
- **自责**："我怎么没早点发现？"
- **羞耻**："别人知道会怎么看我们家？"
- **焦虑**："以后怎么办？还会被骗吗？"
- **无助**："我什么都做不了"

这些情绪都是正常的。你不是一个人。

## 重要提醒

### 这不是你的错

> 骗子专门研究怎么骗老人，有完整的套路和话术。即使是警察、律师的父母也会被骗。

### 这不是父母的错

> 老人不是因为"笨"或"贪心"被骗，而是因为骗子利用了人性的弱点和老人的特点。

### 羞耻感是骗子的帮凶

> 很多骗局能持续，就是因为受害者不敢说出来。打破沉默，才能阻止更多人受害。

## 如何处理自己的情绪

### 1. 允许自己愤怒

愤怒是正常的，但不要向父母发泄。

**健康的愤怒出口：**
- 写下来
- 和朋友倾诉
- 运动发泄
- 报警让骗子受到惩罚

### 2. 把自责转化为行动

**不要想：**
> "我应该多关心父母的"

**要想：**
> "从现在开始，我可以做什么？"

自责不能改变过去，行动可以改变未来。

### 3. 寻求支持

不要一个人扛：
- 和伴侣、朋友倾诉
- 加入反诈互助群
- 寻求心理咨询
- 向社区、警方求助

### 4. 把经历变成力量

很多CONTRIBUTORS（贡献者）说：

> "我把父母的经历写下来，帮助了其他人，感觉好多了。"

把你的经历分享出来，既能帮助他人，也能疗愈自己。

## 如何支持父母

### 1. 第一时间：安抚情绪

父母被骗后，往往比子女更难受：
- 自责
- 害怕子女责怪
- 担心钱追不回来
- 觉得丢脸

**你要做的：**
- 先安抚情绪，不要急着问细节
- 明确告诉父母："这不是你的错"
- 强调："钱没了可以再赚，你没事最重要"

### 2. 处理实际问题

情绪稳定后，一起处理：
- 报警
- 联系银行
- 收集证据
- 评估损失

### 3. 长期心理支持

老人被骗后可能会有：
- 对世界的信任崩塌
- 不敢再接触新事物
- 抑郁、焦虑

**你要做的：**
- 多陪伴，多倾听
- 鼓励老人继续正常生活
- 必要时寻求专业心理咨询
- 帮助老人重建信心

## 把痛苦转化为生产力

### 你可以做的

1. **分享经历**：在这个Wiki上投稿，帮助其他人
2. **参与反诈**：加入社区反诈志愿者
3. **提醒他人**：在朋友圈、群里分享防骗知识
4. **支持其他受害者**：在互助群里帮助刚被骗的人

### 这种转化有什么帮助

- **减少自责**："至少我的经历帮助了别人"
- **获得意义**："这件事不是毫无价值"
- **建立连接**："我不再是孤单一人"
- **重获掌控感**："我可以做点什么"
